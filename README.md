## МИБ браузер
Основными задачами этого МИБ браузера были просмотр содержимого локальных МИБ файлов и отправка запросов по протоколу SNMP к другим хостам.
Обе цели достигаются с помощью использования библиотеки net-snmp, пример сконфигурированной библиотеки и представлен директорией net-snmp-5.7.3.
